# Обновление без остановки из-за отдельных ошибок сборки

Исправление от 24 октября 2026 года.

- `build.sh` компилирует программы и ресурсы по отдельности: `tabletd`, `tablet-tools`, `tabletshell`, `tablet-settings`, `tablet-keyboard`, `tablet-greeter`, `webapp-runner`, погодный шейдер, звуки и переводы.
- `update.sh` автоматически включает безопасный пропуск ошибок компиляции. Если сборка одного компонента не удалась, остальные продолжают собираться.
- **Обязательное условие пропуска:** существует работоспособная ранее установленная версия сбойного компонента. При отсутствии такой версии сборка сообщит об ошибке и не начнёт установку.
- При пропуске программы сохраняются **её старые бинарник, QML-ресурсы и звуки**, а также связанная запись установщика о принадлежащих ему файлах. Для неудачного погодного шейдера также сохраняется старая версия домашнего экрана.
- Статус «ЧАСТИЧНОЕ ОБНОВЛЕНИЕ / PARTIAL UPDATE» перечисляет пропущенные компоненты. Сборка с пропущенными файлами не помещается в кэш полной сборки. Версия установки помечается как `partial`, а перечень пропусков хранится в `~/.local/share/tablet-shell/last-skipped-components`.
- Скрипт очистки устаревших файлов не удаляет ресурсы пропущенных программ. Пользовательские настройки не сбрасываются.
- Неудачное обновление отдельной программы не должно приводить к перезапуску её прежней службы.

## Использование

Из распакованного архива проекта:

```bash
bash ./update.sh --offline
```

Установщик в режиме частичной сборки:

```bash
bash ./install.sh --skip-failed-builds
```

Чтобы потребовать полностью успешную сборку всех компонентов:

```bash
bash ./update.sh --offline --require-all
```

Чтобы не допускать пропуск *именно клавиатуры*:

```bash
bash ./update.sh --offline --require-keyboard
```

На первой установке неизвестный или не собравшийся компонент нельзя безопасно «пропустить» без существующей версии. Результаты автоматических тестов не заменяют реальную сборку с установленными Qt 6 и KDE Frameworks 6 на Arch Linux.
