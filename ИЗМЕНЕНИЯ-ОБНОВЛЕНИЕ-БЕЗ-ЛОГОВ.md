# Обновление без журналирования

- `system/greeter-launch.sh`: cage/libseat/seatd и Qt не записываются в `session.log` и не выводятся на экран входа; stdout/stderr идут в `/dev/null`.
- `system/greeter.sh`: при установке/обновлении удаляет **только старый** `/var/cache/tablet-greeter/session.log` и обновляет скрипт запуска без переключения чужого менеджера входа.
- Все пользовательские `.service` tablet-shell устанавливаются с `StandardOutput=null` и `StandardError=null`, не пополняя журнал systemd сообщениями приложения.
- Все C++/Qt-программы tablet-shell отключают обработчик диагностических сообщений Qt. Удалены `qInfo` и `qWarning` из кода приложений; полезные сообщения CLI и графические уведомления не удалялись.
- `system/base.sh`, `system/cleanup.sh` больше не изменяют настройки/срок хранения **общесистемного** журнала systemd. Системные журналы ОС, включая собственный `seatd.service` (если он существует), этим проектом не отключаются.
- `update.sh`: обновление из Git (только fast-forward для чистой рабочей копии), из другого каталога или из нового ZIP через `--from`. Новая сборка создаётся до замены бинарных файлов. При обновлении сохраняются резервные копии KDE-конфигурации и основных исполняемых файлов.
- `install.sh --update-only`: обновляет код, службы и установленный экран входа, не перезаписывая тему, пользовательскую раскладку, город погоды и основные настройки KDE. Все обычные способы первичной установки сохранены.

## Использование

```bash
./update.sh                      # Git checkout: обновить из отслеживаемой ветки и установить
./update.sh --offline            # только локальные исходники
./update.sh --from ./new.zip     # новый архив tablet-shell
./update.sh --no-greeter-update  # без sudo на экран входа
```

Запускайте от имени обычного пользователя. В случае сбоя резервные копии находятся в `~/.local/state/tablet-shell/backup-*`. Обновление установленных системных компонентов требует прав `sudo`, если они уже были включены.
