# Tablet-shell: GitHub-обновление, стилус и кодинг

## Обновления из настроек
- Раздел «Обновление»: проверка GitHub Vorsente/tablet-shell, подтверждение и установка без сброса пользовательской конфигурации.
- SHA подтверждается перед загрузкой; в архиве запрещены traversal-пути и симлинки, есть лимиты размера.
- Обновление экранного менеджера greetd не выполняется из пользовательского интерфейса без прав администратора.
- Показано предупреждение о локальной сборке с Apple/Pixel, которая может отличаться от содержимого GitHub.

## Меню стилуса
- Полностью удалена лупа вместе с вызовами KWin zoom.
- На её месте Krita с проверкой установки и подсказкой, если её нет.
- Контрастные иконки с фиксированным цветом, выделение активной кнопки, подписи в отдельных подложках.
- Стиль Apple и стиль Pixel используют одну цветовую палитру для каждой темы, увеличены зоны нажатия.

## Режим кодинга
- Новый `bin/coding-mode`: редактор Kate/VSCodium/Code - OSS, полноэкранная анимация перехода, режим фокусировки.
- Энергосбережение, яркость и эффекты KWin сохраняются и восстанавливаются при завершении редактора.
- Отдельные настройки `codingrc`; локальное окружение проектов, открытие последнего файла для Kate.
- Ярлык в меню приложений, кнопка в Пункте управления, раздел в системных настройках.
- Существующие файлы не перезаписываются, в чужие Git-репозитории автокоммиты не создаются.

## Проверки и ограничения
- Автоматические тесты проверяют команды, целостность режима, восстановление питания, яркости и эффектов.
- Qt 6 / KDE Plasma 6 / Wayland не установлены в среде сборки: полноценное исполнение QML и проверка стилуса требуют реального устройства.
- При обновлении из upstream GitHub код Pixel и локальные новшества могут отсутствовать, пока они не опубликованы в GitHub. Поэтому действие выполняется только с подтверждением.
