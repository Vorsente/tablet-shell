# Восстановление панели и оптимизация tablet-shell

## Как применить к уже установленной оболочке

Распакуйте архив в новую папку. Откройте терминал в папке `tablet-shell` и выполните **от своего пользователя, без sudo**:

```bash
bash scripts/repair-panels.sh
```

Скрипт рассчитан на исходную целевую систему проекта: Arch Linux, KDE Plasma 6, Wayland.
Он сначала собирает новый `tabletd` из исходников (нужны g++, pkg-config, Qt 6 и KConfig),
затем сохраняет резервную копию, обновляет демон, сценарии панели, часы и HomeData.
Темы и остальные системные настройки не переустанавливаются. Подождите около 15 секунд.
Для загрузки оптимизированного HomeData выйдите из сеанса и войдите снова.
Резервная копия находится в `~/.local/state/tablet-shell/backup-ДАТА-ВРЕМЯ-PID/`.

Для полной установки / пересборки всех компонентов:

```bash
bash install.sh --no-themes
```

Не используйте старые исполняемые файлы из прежнего `build/` и параметр `--no-build`:
исправления C++ требуют пересборки. Готовые бинарники прежней версии не включены в этот архив.

## Исправления

- Удалено массовое удаление панелей при восстановлении. Отсутствующая панель создаётся без
  очистки всего рабочего стола; повторный запуск восстановления не дублирует статусную панель.
- Исправлена ранняя проверка готовности: восстанавливаются высота и видимость, проверяется
  полный набор виджетов. Раньше скрытая панель могла считаться исправной.
- Планшетный док теперь постоянно видим: режим `dodgewindows` отключён, поскольку на сенсорном
  экране скрытый под окном док трудно вызвать. Это намеренное изменение поведения.
- Панели с посторонними виджетами больше не принимаются за док и не удаляются при смене режима.
  Старые панели только с задачами и разделителями внизу всё ещё распознаются как док оболочки.
- Системный трей сохраняется при переключениях; его дорогое пересоздание не требуется.
- Ошибки D-Bus журналируются, повторные попытки ограничены. Пустые / отсутствующие сценарии
  не запускают восстановление. Неуспешная сборка панели больше не объявляется успешной.
- Устаревшая цепочка переключения отменяется при смене режима и остановке Plasma.
- Список закреплённых приложений принимается и как строка, и как массив; пустой список сохраняется.
  Путь домашней папки корректно экранируется для JavaScript.
- В HomeData блокируются повторные одновременные запросы. При возвращении на рабочий стол
  учитываются интервалы: онлайн-данные — 5 минут, новости — 30 минут, батарея — 25 секунд.
  Изменение города обходит кэш погоды. Ошибка чтения батареи даёт -1, а не NaN.
- Генератор переводов не перезаписывает файлы с неизменившимся содержимым.
- Сборка заранее проверяет инструменты и Qt-модули; `install.sh --city` без аргумента
  завершается понятной ошибкой до изменения установки.

## Проверка и ограничения

```bash
node --test tests/*.test.cjs
```

15 тестов проходят. На исходных файлах из предоставленного архива 12 из этих 15 тестов
завершаются сбоем. Тесты проверяют реальную JavaScript-логику с моделью API Plasma,
функции HomeData и сценарий, генерируемый C++-демоном. Они не заменяют интеграционный запуск KDE.
Дополнительно проверены синтаксис 25 shell-файлов, 6 Python-файлов, 20 JavaScript-файлов
(директивы QML исключены только при синтаксической проверке Node), 12 JSON и 3 XML.
Проверены неизменность времени записи переводов при повторной генерации и отказ `--city` без значения.

Полная сборка и визуальная проверка QML/Plasma **не выполнены**: в среде проверки нет
pkg-config и стека Qt/KDE. Сборка остановилась на проверке зависимостей. Поэтому точную
причину исчезновения панели именно на вашем устройстве без журнала подтвердить нельзя;
исправлены воспроизводимые ошибки исходников. Общий прирост FPS/CPU не измерялся.
Это исправление панели и обнаруженных проблем; оно не является гарантией отсутствия всех
ошибок во всех компонентах проекта.

Если панель всё ещё отсутствует, получите журнал:

```bash
systemctl --user status tabletd.service --no-pager
./install.sh --containments
systemctl --user status plasma-plasmashell.service
```

Не удаляйте `plasma-org.kde.plasma.desktop-appletsrc`: это уничтожит пользовательскую раскладку.
