# Исправление ошибки доступа к build-keyboard.sh

Прямой запуск `./scripts/build-keyboard.sh` заменён на `bash ./scripts/build-keyboard.sh`. Теперь сборка не зависит от сохранения исполняемого бита при распаковке ZIP или от флага `noexec` для каталога с исходниками.

Также через Bash запускаются этапы `build.sh`, `install-lazyvim.sh` и `themes.sh` из установщика. Исполняемые бинарники по-прежнему устанавливаются с правами 755.

Обновление существующей установки: `bash ./update.sh --offline`. Для первичной установки: `bash ./install.sh`. Не запускайте обновление через sudo.
