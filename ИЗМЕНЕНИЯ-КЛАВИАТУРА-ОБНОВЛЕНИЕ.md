# Обновление: защита клавиатуры и безопасная очистка

## Проблема

Сборка `tablet-keyboard` использует закрытые/приватные интерфейсы Qt Wayland.
После обновления Qt в Arch Linux этот код может перестать собираться. Ранее
`./update.sh` полностью прерывался во время сборки клавиатуры.

## Что изменено

- Клавиатура собирается отдельным `scripts/build-keyboard.sh`. Путь к заголовкам
  определяется через `pkg-config`, а новый бинарник заменяет `build/tablet-keyboard`
  только после успешной линковки.
- Если сборка клавиатуры завершилась ошибкой **при обновлении** и уже есть рабочий
  исполняемый файл, `build.sh` продолжает сборку остальных компонентов.
- `install.sh --update-only` в таком случае НЕ копирует новые QML, звуки и бинарник
  клавиатуры и НЕ перезапускает клавиатуру. Она остаётся прежней версией.
- При **первой установке** без старой клавиатуры ошибка её сборки по-прежнему
  останавливает установку: никакой сломанной клавиатуры не устанавливается.
- Сборочные ошибки остаются видимыми в терминале, но не записываются в журналы.
- `scripts/managed-files.py` запоминает отпечатки установленных файлов оболочки.
  В следующих обновлениях удаляются только ранее зарегистрированные и **неизменённые**
  файлы, которых больше нет в проекте. Неизвестные и изменённые файлы остаются.
  На первой установке реестр создаётся; файлы старых версий, не учтённые реестром,
  не удаляются наугад.
- Если клавиатура при обновлении сохраняется, очистка не удаляет её старые файлы.

## Использование

Из распакованной папки новой версии (для установки уже имеющейся системы):

```bash
./update.sh --offline
```

Из прежней папки проекта с новым ZIP:

```bash
./update.sh --from /путь/к/tablet-shell-keyboard-update-2026-10-24.zip
```

Если `tablet-keyboard` снова не соберётся, обновление продолжится с предупреждением,
но её текущий исполняемый файл и интерфейс останутся старыми. Это **не исправляет**
несовместимость Qt автоматически: если старая версия клавиатуры не запускается,
нужно изучить текст ошибки компилятора и обновить исходный код для установленной Qt.

Временно переключить систему на штатную экранную клавиатуру Plasma можно через
«Настройки → Клавиатура → Экранная клавиатура → Plasma» (если она установлена).

Проверки: `node --test tests/*.test.cjs`. В среде сборки без Arch Linux/Qt 6
полная компиляция и работа с KWin не проверены.
