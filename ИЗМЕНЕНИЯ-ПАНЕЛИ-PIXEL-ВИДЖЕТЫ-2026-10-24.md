# tablet-shell: панели, виджеты иконки, анимация оформления

Это дополнение к предыдущему набору исправлений `ИСПРАВЛЕНИЕ-КНОПКА-КЛАВИАТУРА-БЛОКИРОВКА.md`. Исходный дизайн Apple/iPadOS сохранён.

## Домашний экран

- Отступ под точками страниц теперь учитывает зазор над плавающим Plasma dock и различается для Apple/Pixel. Явно заданный пользователем размер дока не перезаписывается.
- Для Pixel добавлен отдельный `PixelWidgetContent.qml`: часы, погода, календарь, батарея, экранное время, печатная машинка и информационные карточки используют иную компоновку и выбор данных; iPad-виджеты сохранены без замены.
- На экран док-панели (`org.ipad.dashboard`) добавлены Material-заголовки с контрастными символами и отдельной визуальной иерархией; Apple остаётся прежним.

## Значки

- Для Pixel добавлены **TabletPixelDark** (светлые символы для тёмной панели) и **TabletPixelLight** (тёмные символы для светлой). Переключение закреплено в пакетах look-and-feel и командах `shell-style` / `appearance`.
- Полный набор Material-подобных значков загружается с проекта [Colloid icon theme](https://github.com/vinceliuice/Colloid-icon-theme), GPL-3.0. Скрипт `scripts/install-material-icons.sh` скачивает его при онлайн-установке и не трогает рабочий набор, если сеть недоступна. В офлайн-режиме используются включённые в проект TabletPixel и установленные fallback-темы.
- Генератор `tablet-tools app-icons --pixel` создаёт круглые Pixel-значки для приложений, которых нет в теме, на основе их собственных иконок. Apple использует прежний отдельный генератор без изменений.
- Фоновый сервис обновляет оба набора по появлении новых приложений. При установке больше не удаляются созданные генератором иконки.
- Иконка режима кодинга заменена на стандартную `applications-development`; в кольце стилуса иконки Krita и снимка экрана встроены локально как SVG и не зависят от темы KDE.

## Переключение дизайна

- Добавлена короткая неблокирующая анимация `theme-transition.qml`, запускаемая только при фактической смене Apple ↔ Pixel и уважающая параметр `transitionAnimation=false`.
- Приложение настроек получило более крупные Material-карточки, округлые иконки в списке разделов и согласованные интервалы. Apple-оформление осталось независимым.

## Ранее исправленные проблемы

- Два меню кнопки питания: предотвращён вызов резервного меню PowerDevil, системная обработка не отключается навсегда.
- Клавиатура: отказ сборки не считается успешным обновлением; при необходимости предусмотрен явный `--keep-keyboard`. Новый исполняемый файл загружается при следующем входе в сеанс.
- Экран блокировки: `lockscreen-sync` проверяет применённые файлы и активный shell package; установленный системный greetd требует отдельного административного обновления при необходимости.

## Команды

После распаковки архива откройте терминал в папке `tablet-shell`:

```bash
bash ./update.sh --offline
```

При **первой** установке (скачивание Material-иконок и обычной темы Apple требует подключения к сети):

```bash
bash ./install.sh
```

После установки выйдите из KDE и войдите снова для обновления KWin-клавиатуры и QML блокировки.

Чтобы скачать иконки отдельно после установки из ZIP без интернета, подключите сеть и выполните:

```bash
bash ./scripts/install-material-icons.sh
~/.local/bin/app-icons-refresh
```

Если применяется отдельный системный greetd (а не только экран блокировки KDE), его конфигурацию требуется обновить с правами администратора:

```bash
sudo ~/.local/share/tablet-shell/system/greeter.sh --refresh
```

## Проверка и ограничения

Проверены скрипты Bash, XML/SVG и 58 автоматических тестов исходных функций и новых регрессий. Реальная сборка и визуальная проверка Qt/Wayland/Plasma 6 в этой среде недоступны. Material-иконки основаны на Colloid и локальном генераторе; это **приближённый к Pixel стиль**, а не фирменный набор иконок Google.
