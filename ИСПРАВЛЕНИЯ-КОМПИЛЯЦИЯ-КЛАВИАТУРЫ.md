# Устранение повторной ошибки `disableQtLogging`

- Убраны все вызовы `disableQtLogging()` из исполняемых программ, включая клавиатуру; подавление диагностических сообщений выполняется через Qt API `qInstallMessageHandler()` напрямую.
- Обновлятор по умолчанию сохраняет старую клавиатуру и продолжает обновление при её ошибке сборки, но помечает результат как **частичное обновление**. Файлы клавиатуры и QML не заменяются частично.
- `bash ./update.sh --offline --require-keyboard` принудительно требует успешную сборку новой клавиатуры.
- Для выявления запуска старого архива выводится путь к использованным исходникам и SHA256 `main.cpp`.
- После успешного обновления новая клавиатура активируется при следующем входе в сеанс.

Важно: среда проверки не содержит Qt6/Plasma. Исправление устраняет конкретное необъявленное имя; другие ошибки при сборке Qt нужно проверять на Arch Linux.
