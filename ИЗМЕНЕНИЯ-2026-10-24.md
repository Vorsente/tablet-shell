# tablet-shell: установка, seatd и оптимизация — 24 октября 2026

## Что изменилось

- **seatd/libseat/cage:** `system/greeter-launch.sh` запускает cage с
  `LIBSEAT_BACKEND=logind` и записывает stdout/stderr в приватный
  `/dev/null`, без создания файлов журнала.
  При повторной установке `system/greeter.sh --refresh` обновляется автоматически,
  **только если** greetd уже использует экран входа tablet-shell. Другие
  менеджеры входа не отключаются. Настройки `vt` и прочие параметры чужих
  секций при обновлении сохраняются.
- **Одна установка:** `./install.sh` пересобирает исходники и применяет
  обновлённые QML, виджеты, панели, настройки KDE и пользовательские службы.
  Исправления C++ не зависят от старых бинарников. Для нового экрана входа:
  `./install.sh --install-greeter` (изменение менеджера входа требует явного выбора).
- **Панели:** после обновления демон перезапускается и отправляется команда
  `Reapply` для немедленной проверки. Существующая логика сохраняет пользовательские
  панели, док и трей, вместо их принудительного удаления.
- **Главный экран:** размещение иконок и виджетов использует побитовые маски
  занятости строк, а `pageEntries` получает предварительно составленный индекс.
  Повторные иконки в очереди обрабатываются через хеш-таблицу вместо линейного поиска.
- **Приложения C++:** единичный расчёт геометрии суперэллипса вместо сотен
  вычислений `pow` и `sin/cos` на каждый значок; `QSet` для поиска активных
  камер и стабилизация списка приложений; ограничение размера сетевых загрузок.
- **Интерфейс:** улучшено выделение стеклянных кнопок при наведении и фокусе,
  добавлено управление клавиатурой, слегка усилены границы карточек.
- **Установщик:** удалена безусловная восьмисекундная задержка, строки
  настроек погоды экранируются, проверяется полнота сборки при `--no-build`,
  пользовательские таймеры и path-службы активируются без нового входа.

## Установка

Распакуйте архив, откройте терминал в каталоге `tablet-shell`:

```bash
./install.sh --no-themes
```

Для первого включения **собственного** экрана входа:

```bash
./install.sh --no-themes --install-greeter
```

Параметр `--no-themes` не перекачивает оформление, если оно уже установлено.
При первой установке рекомендуется обычный `./install.sh`.

## Проверка

```bash
node --test tests/*.test.cjs
bash -n install.sh system/greeter.sh system/greeter-launch.sh
./install.sh --containments
```

Важно: автотесты JavaScript и сценариев установки не заменяют тест
на реальном устройстве с Arch Linux, KDE Plasma 6 и Wayland. Полная сборка Qt 6
и воспроизведение аппаратных ошибок недоступны без этой системы.
