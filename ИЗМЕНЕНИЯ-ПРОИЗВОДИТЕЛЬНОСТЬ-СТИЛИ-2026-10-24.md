# Оптимизация интерфейса tablet-shell — 24.10.2026

## Исправления

1. GPU: однократная композиция погодных шейдеров, полное отключение анимированной погоды по умолчанию, отдельно оставлено плавное переключение день/ночь.
2. Быстрая анимация запуска: аппаратное масштабирование карточки вместо анимации её геометрии; короче тайм-аут ожидания окна.
3. Временная шкала переходов: исправлено ожидание готовности, сокращён финальный зум и блокировка экрана переходом; восстановлен выход по таймеру безопасности.
4. Принудительная смена масштаба всего дисплея KScreen выключена по умолчанию (на слабых устройствах вызывает заметный перерасчёт композитора и просадки кадров).
5. Нижний отступ домашнего экрана синхронизирован с настоящей высотой дока, а старый стандарт 88 px мигрируется без удаления пользовательских параметров.
6. Верхняя статусная панель полностью растянута на экран с выравниванием по центру и нулевым смещением. Существующие виджеты/пользовательские панели сохраняются.
7. Material Pixel: собственный пакет иконок системных действий TabletPixel, адаптивные круглые подложки, новые пропорции иконок, правильные цвета уведомлений в светлом режиме. Apple/MacTahoe остаётся.
8. В одном уведомлении при подключении клавиатуры теперь два предложения и действия печатной машинки + LazyVim, их можно отключать независимо. При непосредственном запуске кодинга показывается двухфразовое уведомление.
9. Экран блокировки: синхронизация из новой LockSurface.qml и отдельный Material-вариант панели пароля и медиа. Для system-greetd требуется обновление с повышением прав.
10. Обновление: кэш компиляции на основе исходников/ABI Qt/компилятора, опциональный ccache, стадийный вывод в терминале, сохранение настроек и старой клавиатуры при ошибке пересборки.

## Ограничения

Невозможно гарантировать отсутствие зависаний на реальном устройстве без сборки и измерения FPS в Arch Linux / KDE Plasma 6 / Qt 6. Иконки сторонних приложений, экспортирующих собственные пиксельные значки в system tray, не подменяются насильственно. Обновление greetd из GUI не запускает sudo без согласия пользователя.
