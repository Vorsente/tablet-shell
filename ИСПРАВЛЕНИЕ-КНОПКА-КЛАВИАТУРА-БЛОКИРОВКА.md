# Исправления: питание, клавиатура и экран блокировки

- Убрано резервное меню KDE (`org.kde.LogoutPrompt`) при удержании питания: приложение показывает только собственное.
- При активном обработчике кнопки планшета PowerDevil получает `PowerButtonAction=0`, для специально выделенных устройств питания используется захват evdev, а обработка в logind блокируется временным inhibitor. Системные файлы logind не изменяются, при остановке демона управление возвращается ОС.
- Обновление по умолчанию не может молча оставить старую клавиатуру. Если сборка не удалась, обновление прекращается до установки (сообщение об ошибке указывает на версии Qt). Для намеренного сохранения старой клавиатуры есть `--keep-keyboard`.
- Убрано принудительное завершение клавиатуры во время обновления: KWin подхватит новый бинарник при следующем входе в сеанс.
- Скрипт блокировки проверяет источник и целевой QML, активный Plasma shell и конфликтующие настройки Greeter Theme. При ошибке установка не сообщает ложного успеха.
- Установщик не ждёт интерактивный пароль sudo в фоновой сессии приложения. При необходимости перезаписи системного экрана входа выводит явное напоминание для отдельного действия администратора.

## Использование

```bash
bash ./update.sh --offline
```

Если новая клавиатура не собирается и нужно всё же обновить остальные компоненты:

```bash
bash ./update.sh --offline --keep-keyboard
```

После успешной установки выйдите из KDE и войдите заново, чтобы KWin перезапустил экранную клавиатуру, а экран блокировки прочитал свежие QML.

Для системного экрана входа на greetd при необходимости:

```bash
sudo ~/.local/share/tablet-shell/system/greeter.sh --refresh
```
