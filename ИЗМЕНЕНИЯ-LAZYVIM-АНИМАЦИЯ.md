# Обновление режима кодинга — LazyVim и анимация

- `bin/coding-mode`: вместо выбора Kate/VSCodium/Code OSS используется `konsole --nofork --fullscreen -e env NVIM_APPNAME=tablet-shell-lazyvim nvim .`. Консоль отслеживается до закрытия; после выхода восстанавливаются настройки питания, яркость, эффекты KWin, фокусировка. Содержимое проектов не меняется.
- `src/tabletshell/ModeTransition.qml`: отдельная сцена LazyVim с появлением интерфейса терминала и последовательным проявлением строк кода; обратный переход остаётся. Ожидание появления окна и защитный тайм-аут.
- `src/tablet-settings/qml/Main.qml`: описание LazyVim в разделе кодинга без устаревшего выбора редакторов.
- `scripts/install-lazyvim.sh`: idempotent-установка официального LazyVim Starter в отдельной конфигурации; Neovim пользователя не затрагивается; плагины устанавливаются без лог-файлов. Если загрузка сорвётся, временные файлы удаляются, при повторном запуске установка продолжится.
- `install.sh`: установка зависимостей через pacman (включая Krita для меню стилуса и power-profiles-daemon) в том числе на обновлениях, запуск новой процедуры настройки LazyVim; `update.sh` вызывает этот режим автоматически.
- `applications/coding-mode.desktop`: название приложения уточнено.
- Добавлены тесты для безопасной повторной установки, отказа сети, сохранения существующего nvim и анимации.

## Использование

Первичная установка:

```bash
./install.sh
```

Обновление локальной версии проекта:

```bash
./update.sh --offline
```

Первое получение GitHub Starter и плагинов требует доступа к сети. Системные пакеты устанавливаются через обычный механизм sudo/pacman, который может попросить пароль в терминале. Графическое обновление из Настроек может потребовать первичной установки пакетов из терминала.

LazyVim требует Neovim 0.11.2+; система использует отдельную переменную `NVIM_APPNAME=tablet-shell-lazyvim`.
